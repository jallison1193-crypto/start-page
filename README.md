# Start page

A personal browser start page: clock, Lansdowne weather, search (Google, ChatGPT, Claude), editable site groups, a month calendar and a Google Calendar agenda, over a drifting-dust night sky.

Everything lives in `index.html`. Sites and settings are saved in the browser's local storage, so use **Edit sites > Back up** to keep a copy.

Live at https://jallison1193-crypto.github.io/start-page/
