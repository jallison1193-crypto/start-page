# Start page

A personal browser start page built as a snap grid of widgets: clock, search (Google, Gemini, DuckDuckGo, ChatGPT, Claude), weather, moon and daylight, live SEPTA trains, site groups, calendar, quick note, tasks and a silent focus timer.

- **Arrange** lets you drag widgets around and pick one of four sizes (Small, Medium, Large, Wide). Everything snaps to the grid.
- **Settings** has theme sets (Deep space, Nebula, Aurora, Lunar), dark, light, match Windows or a schedule (sunrise to sunset, or set times), accent colors, widget on/off, weather location, train station and backup.

Everything lives in `index.html`. Your setup is saved in the browser's local storage, so use **Settings > Backup** to keep a copy.

Live at https://jallison1193-crypto.github.io/start-page/
